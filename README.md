# Netflix Data Cleaning

## Description
This project performs data cleaning on the Netflix Movies and TV Shows dataset using Python and Pandas.

## Tasks Performed
- Loaded the Netflix dataset
- Checked the dataset structure
- Checked for missing values
- Checked for duplicate rows
- Filled missing values with "Unknown"
- Verified that no missing values remained
- Saved the cleaned dataset as a new CSV file

## Dataset
Netflix Movies and TV Shows dataset containing 8,807 records and 12 columns.

## Tools Used
- Python
- Pandas
- PyCharm

## Files
- `task1_data_cleaning.py` – Python code used for data cleaning
- `netflix_titles.csv` – Original dataset
- `netflix_titles_cleaned.csv` – Cleaned dataset
